# Chapter 3

## Assignment

Build a command-line number analyzer. Read a sequence of integers from the user and report its count, sum, average, minimum, and maximum. Organize the calculations into functions and return the results together in a tuple. Handle invalid numbers, an empty sequence, and sums that overflow the chosen integer type.

### Concepts to practice

- Primitive numeric types and explicit casts
- Arrays, slices, and tuples
- Loops and user input
- Functions with parameters and return values
- Handling empty input and integer overflow

For example, given `4 8 2`, the program should report a count of `3`, sum of `14`, average of about `4.67`, minimum of `2`, and maximum of `8`.
