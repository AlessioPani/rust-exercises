# Chapter 3



## Assignment

Create an interactive command-line calculator. Show a menu of arithmetic operations, read the user's choices and numbers, calculate and display the result, then let the user perform another calculation or quit.

Handle invalid menu choices, malformed numbers, and division by zero without crashing. Organize the program into functions that take parameters and return values, and use an enum to represent the selected operation. Use explicit type conversions where needed.

### Concepts to practice

- `if` and `match` expressions
- Loops and user input
- Enums
- Functions with parameters and return values
- Numeric parsing and explicit type conversions
- Handling invalid input
